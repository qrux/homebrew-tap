# qrux/tap

Homebrew formulae by Qrux.

```
brew install qrux/tap/qclone
```

[qclone](https://github.com/qrux/qclone): prettier local rclone, with cleaner
syntax, adaptive parallelism and degraded-SSD rescue.

The formulae here are written by each project's release; change them there.

```
brew install qrux/tap/pow
```

[pow](https://github.com/qrux/pow): a live view of power, load, temperature
and fans on Apple silicon, in the terminal.
